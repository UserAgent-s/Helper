# ADR 0004: Переключение OpenAI Realtime / Anthropic Claude через раздельные пайплайны

Дата: 2026-10-15. Статус: принято.

## Контекст

Нужно два рабочих пути подсказок: OpenAI Realtime (принимает аудио) и Anthropic Claude Messages API (принимает только текст). Рассматривались:

1. **Раздельные пайплайны.** OpenAI: системный звук → Realtime → текст. Claude: системный звук → локальное инкрементальное распознавание → Messages API → текст.
2. **Общее распознавание для всех провайдеров.** Всегда локальный STT, затем текст любому провайдеру.

## Решение

Вариант 1. Существенных препятствий не найдено. Общий STT ухудшил бы путь OpenAI: добавил бы задержку WhisperKit на критический путь (противоречит ADR 0002), потерял бы серверный VAD/turn detection Realtime и сделал бы аудио-модель текстовой.

Различия не скрываются одной абстракцией:

- `ProviderRoutingAnswersController` — единственный `ModeController` для `.answers`; на старте фиксирует `AnswerSessionConfiguration`, запускает ровно один маршрут, пересылает события только активного провайдера.
- OpenAI-маршрут — существующий `AnswersModeController` + `OpenAIRealtimeAnswerClient` (модель и reasoning effort теперь из настроек, usage из `response.done`).
- Claude-маршрут — `TranscribedAnswersModeController` с явными интерфейсами: `SpeechFragmentRecognizing` (распознавание), `QuestionReadinessDetecting` (готовность вопроса), `TextAnswerGenerating` (потоковая генерация), `SessionTranscriptContext` (контекст сессии), `UtteranceSegmenter` (паузы/фрагменты).
- Общие инструкции — `AnswerInstructionsBuilder` с адаптацией `.realtimeAudio` / `.transcriptText`.

## Следствия

- Смена провайдера/модели только в Passive; настройки, изменённые во время сессии, помечаются как неприменённые.
- Каждый старт увеличивает generation-токен; события с устаревшим токеном или от неактивного провайдера отбрасываются — запоздалый ответ не показывается.
- Ошибка провайдера никогда не приводит к отправке данных другому провайдеру.
- Модель Whisper остаётся загруженной между сессиями (общий кеш с Recording) ради времени старта; аудио, задачи, сеть и контекст освобождаются при остановке.
- Claude API вызывается напрямую по HTTPS (официального Swift SDK нет), без Claude Code CLI и без OAuth-токенов подписки.

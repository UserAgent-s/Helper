# Диагностика типичных ошибок

## `xcodegen: command not found`

XcodeGen не установлен. Установите и сгенерируйте проект:

```bash
brew install xcodegen
xcodegen generate
```

## `answers` завершается ошибкой сразу после выбора режима

Наиболее вероятная причина — не задан API-ключ. Откройте Настройки (или экран onboarding при первом запуске) и сохраните ключ формата `sk-…`. Приложение проверяет только формат ключа локально; реальная авторизация проверяется только при первом обращении к Realtime API. Если ключ задан, но ошибка сохраняется — проверьте баланс/статус ключа на стороне OpenAI (приложение не может это определить локально).

## `answers` не отвечает / не слышит вопрос

- Проверьте, что выбран правильный источник системного звука (Настройки → «Источник системного звука»). Если источник не выбран, `answers` захватывает весь дисплей — это шире контракта продукта и может ловить посторонний звук.
- Проверьте разрешение Screen Recording (Настройки → «Разрешения»). После первой выдачи разрешения система может потребовать перезапуск приложения.
- Убедитесь, что вопрос действительно прозвучал — модель намеренно ждёт (`⟦WAIT_FOR_QUESTION⟧`) при постановке задачи без явного вопроса. Используйте кнопку/горячую клавишу «Ответить сейчас» (по умолчанию `⌥Return`), чтобы принудительно получить ответ по уже накопленному контексту.

## `recording` не запускается или сразу останавливается

- Проверьте разрешения Screen Recording И Microphone (`recording` требует оба).
- Проверьте статус локальной Whisper-модели в onboarding-экране или через первый запуск `recording` — если модель ещё не скачана, первая загрузка требует сети и может занять время в зависимости от размера модели (`small` по умолчанию).

## Live-transcript в главном окне обновляется рывками, а не по словам

Ожидаемо в текущей реализации: live-transcript обновляется на границе чанка транскрипции (~8 секунд), а не пословно в реальном времени. Это не ошибка — см. `docs/implementation-status.md`, этап 07.

## История/поиск не находит ожидаемый текст

Поиск использует SQLite FTS5 со стандартным токенайзером `unicode61` — точное совпадение словоформы, без стемминга. Запрос "бюджет" не найдёт "бюджете". Попробуйте более короткий/точный фрагмент.

## Экспорт (transcript/summary/diagnostics) не создаёт файл

Проверьте, что диалог `NSSavePanel` не был закрыт нажатием «Отмена», и что у приложения есть право записи в выбранную папку (App Sandbox разрешает запись только в места, явно выбранные пользователем через системный диалог — это ожидаемое поведение sandbox, а не ошибка).

## `swift build`/`swift test` падает с ошибкой WhisperKit/зависимости

Убедитесь, что сеть доступна при первом разрешении зависимостей SwiftPM (`argmaxinc/argmax-oss-swift`, версия закреплена в `Package.resolved`). При повторных сборках зависимость уже закеширована в `.build/checkouts` и сеть не требуется.

## SQLite ошибка / "disk full" при записи истории

Приложение не удаляет и не пытается автоматически чинить повреждённую базу. Ошибка останавливает активный режим и показывает сообщение вместо тихой потери данных. Освободите место на диске; при повреждении базы сделайте резервную копию файла `~/Library/Application Support/UserAgent057/useragent057.sqlite3` перед любыми ручными действиями.

## Приложение не понимает, что делать при отсутствии интернета

- `passive` и `recording` работают полностью офлайн (после того как Whisper-модель уже загружена один раз).
- `answers` и создание саммари требуют сети (OpenAI API) — без сети оба покажут понятную ошибку и не оставят приложение в неопределённом состоянии (переход в `passive` при сбое режима).

# Приватность MeetingAssistant

## Passive (по умолчанию при запуске)

- Не захватывает системный звук и микрофон, не обращается в сеть, не сохраняет контент.
- Разрешения не запрашиваются, пока вы не выберете другой режим.

## Answers

Провайдер выбирается в Настройках (только в Passive). Главное окно всегда показывает текущего провайдера, модель, что уходит наружу, состояние захвата и сохраняется ли история или аудио.

### OpenAI Realtime

- Захватывает системный звук выбранного приложения (или всего дисплея, если приложение не выбрано). Требует Screen Recording, микрофон не нужен.
- Аудио непрерывно передаётся в `wss://api.openai.com/v1/realtime` вместе с инструкциями и профилем кандидата.
- В локальную историю попадает показанный ответ и текст вопроса, расшифрованный локально WhisperKit из окна контекста (после начала показа ответа).

### Anthropic Claude

- Захватывает системный звук выбранного приложения. Требует Screen Recording.
- Звук распознаётся локально WhisperKit по фрагментам между паузами. Аудио в сеть не отправляется.
- В `https://api.anthropic.com/v1/messages` уходит только текст: распознанная речь с момента последнего показанного ответа, до двух предыдущих пар вопрос-ответ, инструкции и профиль кандидата.
- Опция «server-side fallback» (по умолчанию включена для Opus 5.5 и Sonnet 5.5) позволяет Anthropic при отказе модели ответить другой моделью Claude внутри того же запроса. Данные другому провайдеру не уходят; фактическая модель видна в статусе сессии.
- В локальную историю попадает распознанный вопрос и показанный ответ.

### «Мой опыт» и память прошлых ответов

- Заметки базы знаний хранятся локально в той же SQLite-базе (таблица `knowledge_notes`). Включённые заметки (до ~40 000 символов) отправляются выбранному провайдеру в инструкциях каждой сессии Answers; выключенные не отправляются.
- При «Памяти прошлых ответов» > 0 последние N завершённых пар вопрос-ответ из локальной истории отправляются провайдеру в инструкциях сессии.
- Импортированные файлы не копируются: сохраняется только извлечённый текст и имя файла.

### Общее для обоих

- Аудио Answers на диск не пишется никогда.
- При остановке очищаются очередь аудио, контекст сессии и предыдущие обмены; разговор не переносится между провайдерами.
- При ошибке провайдера запрос не перенаправляется другому провайдеру.

## Recording

- Захватывает системный звук и микрофон (оба разрешения).
- Транскрипция только локально через WhisperKit, в сеть ничего не уходит.
- WAV-файлы пишутся только при включённом «Сохранять аудио на диск».
- По завершении встречи транскрипт экспортируется в Markdown на Рабочий стол.

## Секреты

- Ключи OpenAI и Anthropic хранятся в macOS Keychain (`KeychainSecretStore`, сервисы `com.local.MeetingAssistant.openai` и `com.local.MeetingAssistant.anthropic`, доступность `AfterFirstUnlockThisDeviceOnly`).
- Ключ OpenAI из старых версий (UserDefaults, `com.local.MeetingAssistant.settings.openaiAPIKey`) переносится при запуске: запись в Keychain → проверка чтением → удаление старого значения. При ошибке записи или проверки старое значение не удаляется и продолжает использоваться как резерв; в Настройках это видно. Если в Keychain уже лежит другой ключ, используется он, а старое значение не трогается.
- Ключи не попадают в SQLite, диагностику, логи и исходный код. Известные форматы ключей дополнительно редактируются в логах (`SecretRedactor`).
- Компромисс: при ad-hoc-подписи macOS может повторно спрашивать доступ к Keychain после пересборки (меняется подпись). Со стабильной локальной идентичностью подписи запрос появляется один раз.

## Diagnostic export

По умолчанию JSON содержит только версию, режим/фазу, статусы разрешений, счётчики метрик и сводку сессии Answers: провайдер, модель (настроенная и фактическая), usage, оценку стоимости с источником тарифа, задержки p50/p95, коды ошибок, число переподключений, состояние порога расходов. Без аудио, текста разговора, профиля и ключей.

История вопросов-ответов и транскрипты встреч добавляются только при включённой опции «Настройки» → «Диагностика» → «Включать текст…». Такой файл храните как саму историю.

Технический лог Realtime (`realtime_diag.log` рядом с базой) содержит только события подключения и коды ошибок, без контента; ключи в нём редактируются.

## Оверлей и демонстрация экрана

Оверлей — обычное окно поверх других (`sharingType = .readOnly`). Приложение не скрывает его от захвата экрана и не обещает невидимости: при демонстрации экрана собеседник может его видеть.

## Согласие участников

Если на встрече присутствуют другие люди, получите их согласие на запись и обработку речи по правилам вашей юрисдикции. Приложение предназначено для тренировок и собеседований, где помощь разрешена.

## Локальные данные и удаление

- База: `~/Library/Application Support/MeetingAssistant/meetingassistant.sqlite3` (+ `-wal`/`-shm`).
- Удаление записей и всей истории — экран «История».
- Полное удаление: закрыть приложение, удалить `~/Library/Application Support/MeetingAssistant/`, удалить ключи кнопками «Удалить» в Настройках (удаляют из Keychain и старого хранилища).
- Модель Whisper кешируется WhisperKit вне каталога приложения; удаляется отдельно.

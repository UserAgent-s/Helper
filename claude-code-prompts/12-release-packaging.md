# Этап 12. Сборка, onboarding и упаковка приложения

## Цель

Подготовь воспроизводимую локальную release-сборку и понятный пользовательский запуск без ослабления требований безопасности.

## Пользовательский сценарий

Добавь onboarding, который:

1. Объясняет три режима без двусмысленности.
2. Не запрашивает разрешения при простом запуске.
3. Позволяет ввести API-ключ в Keychain.
4. Объясняет Screen Recording для `answers` и `recording`.
5. Объясняет Microphone permission только для `recording`.
6. Позволяет выбрать приложение-источник звука.
7. Проверяет наличие/загрузку локальной Whisper-модели до первой записи, но не блокирует `passive`.
8. Показывает напоминание о согласии участников на запись.

## Menu bar

Создай однозначный menu bar UI:

- `Пассивный`;
- `Ответы`;
- `Запись митинга`;
- открыть историю;
- настройки;
- завершить приложение.

Цвет/иконка дополняют текст, но не заменяют его. При переходе или ошибке показывай фактическое состояние, а не желаемый режим.

## Build configuration

- Debug и Release конфигурации;
- Release не включает подробные content logs;
- bundle resources и модельные assets управляются явно;
- секреты отсутствуют во всех конфигурациях;
- архитектура arm64 обязательна; universal build допустим, если зависимости поддерживают его;
- version/build number задаются централизованно;
- Hardened Runtime и sandbox проверены;
- подпись/notarization документированы, но не выполняются без credentials пользователя.

## Проверки

1. Выполни clean Release build.
2. Проверь запуск без базы/настроек: режим `passive`.
3. Проверь запуск без API-ключа: passive/recording доступны, answers показывает настройку, но не падает.
4. Проверь запуск без Whisper-модели: passive/answers доступны, recording предлагает установить модель.
5. Проверь, что release bundle не содержит ключей, пользовательских данных, WAV/PCM fixtures вне test bundle и debug logs.
6. Проверь stop/quit во всех режимах.

## Критерии приёмки

- Получается воспроизводимая `.app` Release-сборка либо точно описан внешний blocker подписи/окружения.
- Приложение безопасно запускается без разрешений и секретов.
- Пользователь может понять текущий режим без догадок.
- Release bundle не содержит пользовательские данные и тестовое аудио.

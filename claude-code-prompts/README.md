# Набор промптов MeetingAssistant для Claude Code

Этот каталог содержит последовательный план реализации нативного macOS-приложения с тремя режимами: быстрые ответы, локальная запись митинга и полностью пассивное состояние.

## Использование

1. Поместите каталог `claude-code-prompts` в корень репозитория.
2. Откройте репозиторий в Claude Code.
3. Вставьте содержимое отдельного файла `BASE_PROMPT_CLAUDE_CODE_RU.md`.
4. Claude Code должен выполнять пронумерованные файлы строго по порядку.

Критический архитектурный принцип: режим быстрых ответов отправляет аудио непосредственно в Realtime API. Все речевые ходы после прошлого ответа считаются контекстом следующего вопроса и сохраняются в Realtime conversation до автоматического ответа или действия `Ответить сейчас`. Полная транскрипция существует только в режиме записи. Локальная транскрипция ограниченного окна «контекст + вопрос» для журнала выполняется асинхронно после начала вывода ответа и никогда не блокирует его.

В режиме быстрых ответов каждый ответ целиком формируется на языке текущего вопроса и звучит как краткий, технически точный ответ сильного senior software engineer на собеседовании.

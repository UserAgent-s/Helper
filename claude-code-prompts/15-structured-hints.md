# Этап 15. Структурированные подсказки: мгновенный ответ, раскрытие, лента

Контекст: `docs/product-vision.md`, ADR 0007. Критический путь мгновенной подсказки не меняется; этап добавляет структуру поверх `AnswerStreamEvent`.

## Домен

1. Добавь `Hint` (id, createdAt, question?, text, status, expansion?) и `HintExpansion` (text, status); статус — `streaming` / `completed` / `failed(reason)`.
2. Добавь `HintFeed` (actor): подписывается на `AnswerSessionControlling.streamEvents()` и `ModeCoordinator.stateUpdates()`; `streaming` создаёт или обновляет текущую подсказку, `completed` завершает её, `cancelled` помечает ошибкой, `noContext` даёт событие уведомления. Хранит последние N подсказок сессии; `events()` отдаёт снимок при подписке и затем изменения; состояние сессии (режим, фаза, провайдер, модель) входит в снимок.
3. `QuestionAnswerLogger` публикует `updates()` — поток сохранённых пар. `HintFeed` привязывает вопрос к подсказке по совпадению текста завершённого ответа и далее обновляет вопрос по id пары, когда распознавание закончилось.
4. Добавь протокол `HintExpanding`: по вопросу и короткому ответу возвращает поток текста раскрытия. `HintFeed.expand(id)` запускает ровно одно раскрытие на подсказку, стримит текст в событие, сохраняет результат в пару вопрос-ответ (`expansionText`).
5. `TextAnswerRequest` получает необязательный `userMessage`, чтобы тот же клиент Anthropic формировал запрос раскрытия без транскрипта. Инструкции раскрытия строятся `AnswerInstructionsBuilder.expansionInstructions(...)`: та же роль, те же области, тот же язык вопроса, формат «подробно»: структура, обоснование, компромиссы, пример; без повторения короткого ответа дословно.

## Провайдеры

- Claude: раскрытие через `AnthropicMessagesAnswerClient` со стримом.
- OpenAI Realtime: Realtime-модели недоступны вне сокета, поэтому раскрытие идёт через Responses API текстовой моделью саммари из настроек, без стрима. Данные не покидают провайдера активной сессии; при отсутствии ключа — понятная ошибка в статусе раскрытия.

## Persistence

- Миграция v4: `qa_entries.expansion_text`; `QuestionAnswerPair.expansionText`; `save` обновляет поле; `history` возвращает его.

## Приложение

- `CompositionRoot` создаёт `HintFeed` и `ProviderHintExpander`, выбирающий реализацию по провайдеру активной конфигурации.
- История вопрос-ответ показывает раскрытие под ответом, если оно есть.

## Тесты

- Поток событий: `streaming` → `completed` даёт одну подсказку с финальным текстом; `cancelled` до первого текста не создаёт подсказку.
- Вопрос привязывается после обновления пары; повторное обновление меняет вопрос у той же подсказки.
- Повторный `expand` той же подсказки не создаёт второй запрос; ошибка раскрытия не трогает текст мгновенной подсказки.
- Запрос раскрытия Anthropic содержит `userMessage` и не содержит тегов `<transcript>`.
- Снимок при подписке содержит уже накопленные подсказки.

## Критерии приёмки

`make verify-fast` проходит; локальный оверлей ведёт себя как раньше (существующие тесты редьюсера не изменены); `docs/implementation-status.md` обновлён.

# Этап 14. Профильные области и подключаемая память

Контекст: `docs/product-vision.md`, ADR 0006. Цель этапа — превратить фиксированный профиль собеседования в набор подключаемых профильных областей со своей памятью, не меняя критический путь ответа.

## Домен

1. Добавь `ExpertDomain` (id, name, role, guidance, isActive, sortOrder, updatedAt) и протокол `ExpertDomainRepository` (save, delete, all).
2. Добавь `ExpertDomainPresets` с тремя встроенными областями с фиксированными UUID, тексты которых дословно переносят прежние секции `InterviewAnswerProfile` (PHP / backend, System design, Behavioral). Сидирование идемпотентно; старая настройка профиля переносится один раз: конкретный профиль активирует одну область, «Авто» — все три.
3. Расширь `KnowledgeNote`: `domainID: UUID?` и `origin` (`manual` / `folder`). Удаление области обнуляет привязку её заметок.
4. `KnowledgeContextBuilder.build(notes:domains:budget:)` включает общие заметки и заметки активных областей; в заголовке заметки указывай область. Заметки неактивных областей не попадают в текст.
5. `AnswerInstructionsBuilder.build` принимает `[ExpertDomain]` вместо `InterviewAnswerProfile`. Секция «Expert areas» перечисляет роль и правила каждой активной области и требует молча выбрать подходящую под вопрос; при пустом списке поведение совпадает с прежним «Авто». Удали `InterviewAnswerProfile` из публичного API домена, оставив только миграцию строки настройки.
6. `AnswerSessionConfiguration.answerProfile` замени на `expertAreas: [String]`; отпечаток `LiveAnswerContext` учитывает активные области.
7. Добавь `KnowledgeLibrary` (actor): единая точка для областей, заметок, сидирования и синхронизации папки. Возвращает снимок (области, заметки, контекст). UI и `prepare` маршрутизатора работают только через него.
8. Добавь чистый план синхронизации папки: вход — список файлов (относительный путь, содержимое), существующие заметки и области; выход — заметки на сохранение, id на удаление, области на создание. Id заметки детерминирован от относительного пути; выключенность существующей заметки сохраняется; подпапка = область, файлы в корне — общие.

## Persistence

- Миграция v3: таблица `expert_domains`; `knowledge_notes` получает `domain_id` и `origin`.
- `SQLiteExpertDomainRepository`; `SQLiteKnowledgeNoteRepository` читает и пишет новые поля; `delete` области обнуляет `domain_id` в одной транзакции.

## Приложение

- Каталог `Knowledge/` в каталоге данных создаётся при запуске. Читатель папки собирает `.md` и `.txt` (лимит размера как при импорте), наблюдатель на FSEvents вызывает синхронизацию с задержкой около секунды; синхронизация также выполняется при запуске, по кнопке и перед стартом Answers.
- Окно «Мой опыт» становится окном «Память»: список областей с переключателями, добавление и редактирование области (название, роль, правила), кнопки «Открыть папку знаний» и «Синхронизировать», у заметок — выбор области и признак источника (папка/вручную).
- Из Settings удали «Профиль ответа»; на его месте поясни, где настраиваются области.
- Строка «Память» в панели статуса: сколько областей активно, сколько заметок в подсказках, сколько прошлых ответов.
- Диагностика: вместо `answerProfile` — список названий активных областей.

## Тесты

- Сидирование и перенос старого профиля (все четыре значения, повторный запуск ничего не дублирует).
- Контекст: заметка неактивной области отсутствует в тексте инструкций; общая заметка присутствует всегда; бюджет общий.
- Инструкции: две активные области дают одну секцию с обоими названиями; пустой список — прежний текст.
- План синхронизации: новый файл, изменённый файл, удалённый файл, файл в подпапке создаёт область, выключенная заметка остаётся выключенной после обновления файла.
- Репозитории: миграция на существующей БД v2 сохраняет старые заметки как общие; удаление области обнуляет привязку.
- App: настройки переживают перезапуск; `AppSettingsStore` больше не хранит профиль, кроме чтения для миграции.

## Критерии приёмки

`make verify-fast` проходит; в `docs/implementation-status.md` записаны неочевидные решения; README и `docs/privacy.md` описывают папку знаний и области; ни одна заметка неактивной области не встречается в тексте инструкций в тестах.

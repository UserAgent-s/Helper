# Этап 16. Удалённый экран: сервер в локальной сети и веб-интерфейс

Контекст: `docs/product-vision.md`, ADR 0007. Подсказки должны читаться на другом Mac или телефоне в той же сети; интерфейс рассчитан прежде всего на большой экран.

## Модуль RemoteDisplay (новый SwiftPM-таргет, зависит только от Domain)

1. `RemoteDisplayServer` (actor): `start(configuration)`, `stop()`, `broadcast(message)`, `commands()`; состояние — порты, число клиентов. HTTP-слушатель на порту P отдаёт страницу (`GET /`), `GET /health` возвращает JSON без контента. WebSocket-слушатель (`NWProtocolWebSocket`) на порту P+1: первое сообщение клиента — `auth` с токеном за ограниченное время, иначе соединение закрывается; после авторизации клиент получает снимок и дальше все события.
2. Протокол сообщений — JSON с полем `type`. Сервер → клиент: `hello`, `snapshot`, `hint.started`, `hint.updated`, `hint.completed`, `hint.expansion`, `session`, `toast`. Клиент → сервер: `auth`, `answer_now`, `expand`, `reset_context`, `set_mode`, `ping`. Кодирование событий `HintFeedEvent` в сообщения — отдельный тип с тестами.
3. Сервер не логирует токен и содержимое подсказок. Порт по умолчанию 8765, настраиваемый; занятый порт даёт понятную ошибку в UI, а не падение.
4. Bonjour: сервис `_meetinghints._tcp` на HTTP-слушателе.

## Веб-интерфейс

- Один файл `Resources/RemoteDisplay/index.html` без сборки и внешних зависимостей; загружается приложением и отдаётся сервером.
- Токен берётся из `?t=` в адресе и хранится в `sessionStorage`; WebSocket переподключается с задержкой.
- Экран Mac: слева лента подсказок (новые сверху, индикатор потока), справа выбранная подсказка с вопросом, коротким ответом и раскрытием; сверху строка состояния (режим, провайдер, модель, соединение). Кнопки: «Ответить сейчас», «Подробнее», «Сбросить контекст», переключение Passive/Answers. На ширине до 800 px блоки в столбик.
- Тёмная и светлая темы по системной настройке; текст подсказки крупный, читается с расстояния.

## Приложение

- `RemoteDisplayCoordinator`: следит за переключателем «Удалённый экран», запускает и останавливает сервер, транслирует события `HintFeed`, выполняет команды через `ManualAnswerTrigger`, `HintFeed`, `AnswerSessionControlling`, `ModeCoordinator`. В `passive` транслируется только состояние сессии.
- Токен сопряжения хранится в настройках, перевыпускается кнопкой; в Settings — ссылка для каждого IPv4-адреса Mac и QR-код первой ссылки.
- `Info.plist`: `NSLocalNetworkUsageDescription`, `NSBonjourServices`; entitlements: `com.apple.security.network.server`.

## Тесты

- Сервер на эфемерном порту: страница отдаётся по HTTP; WebSocket без `auth` закрывается; с верным токеном приходит `hello` и `snapshot`; команда `answer_now` доходит до потока команд; `broadcast` доставляется двум клиентам.
- Кодирование: каждое событие ленты имеет ожидаемый `type`; текст не теряется; даты в ISO 8601.
- Координатор: при выключенном переключателе сервер не запускается; в `passive` сообщения не содержат текста подсказок.

## Критерии приёмки

`make verify-fast` проходит; README описывает подключение с другого устройства и границы безопасности; `docs/privacy.md` и `docs/product-contract.md` обновлены согласно ADR 0007; порты не слушаются при выключенном переключателе.
